개인정보처리방침

유튜브 채널 업로더 · 운영: souludens
시행일: 2026년 11월 14일

적용 범위

운영자 개인의 YouTube 채널 업로드·관리 도구에 적용됩니다. 공개 홈페이지는 안내용이며 방문자의 Google 계정 연결을 받지 않습니다.

처리하는 정보와 목적

Google OAuth 승인 범위에서 채널 ID·이름, 영상 ID·제목·설명·공개 및 예약 정보, 썸네일과 재생목록 정보를 처리합니다. 운영자가 지정한 영상·이미지·설명문을 YouTube에 전송하고, 인증 유지를 위해 접근·갱신 토큰을 사용합니다. 목적은 채널 확인, 영상 업로드, 메타데이터 수정, 예약 공개와 재생목록 관리입니다. Google 비밀번호는 수집하지 않습니다.

저장과 보호

채널별 토큰은 운영자의 Windows 사용자 계정에 연결된 DPAPI로 암호화하여 보관합니다. 요청 시 토큰을 메모리에서 사용하며 처리 과정에서 임시 파일을 사용할 수 있습니다. 채널 식별 정보·작업 결과·영상 ID는 작업 기록에 보관할 수 있습니다. 인증 파일과 토큰은 이 공개 사이트나 공개 GitHub 저장소에 게시하지 않습니다.

전송과 외부 서비스

인증 및 채널 관리 요청은 Google·YouTube API로 전송됩니다. 운영자가 작업을 지시하는 AI 서비스와 실행 환경은 작업에 필요한 데이터에 접근할 수 있으며 각 서비스의 정책도 적용됩니다. 도구는 Google 사용자 데이터를 판매하거나 광고 타기팅에 이용하지 않습니다.

보관·삭제·연결 해제

인증정보는 연결 유지 기간 보관하고, 연결 종료 시 운영자가 토큰과 관련 임시 파일을 삭제합니다. 작업 기록은 운영상 필요한 기간 보관 후 삭제합니다. Google 계정의 서드 파티 연결 관리에서 접근 권한을 철회할 수 있습니다. 로컬 파일 삭제와 별개로 이미 업로드한 영상은 YouTube Studio에서 관리·삭제합니다.

홈페이지와 문의

자체 분석 도구나 광고 추적 코드를 사용하지 않습니다. 호스팅 제공자인 GitHub는 서비스 운영을 위해 접속 정보를 처리할 수 있습니다. GitHub 개인정보처리방침을 참고하세요. 문의·삭제 요청: GitHub 문의 게시판. 게시판은 공개되므로 토큰·비밀번호·개인정보를 올리지 마세요.

Google API 데이터 이용

Google API에서 받은 정보의 사용 및 다른 앱으로의 전송은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다. YouTube 이용에는 YouTube 서비스 약관과 Google 개인정보처리방침이 적용됩니다.

변경 안내

처리 방식이 변경되면 이 페이지에 변경 내용과 시행일을 게시합니다.
